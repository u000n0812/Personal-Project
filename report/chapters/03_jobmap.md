# 생산관리 직무 지도

## 세부직무 9개와 계획 층위

| # | 세부직무 | 계획 층위 | 한 줄 정의 |
|---|---|---|---|
| 4.1 | 수요·공급 계획(S&OP) | 전술 | 시장 수요와 공급 능력을 맞춰 "무엇을 얼마나" 정한다 |
| 4.2 | 생산계획·스케줄링 | 전술–운영 | 공급 계획을 팹별·주차별 웨이퍼 투입·출하 계획으로 바꾼다 |
| 4.3 | Capa 관리·설비 투자 계획 | 전략–전술 | 필요한 생산능력을 계산하고 설비 투자·공정 전환을 기획한다 |
| 4.4 | 라인 운영(재공·디스패칭) | 운영 | 팹 안의 웨이퍼 흐름을 통제해 생산기간과 출하량을 지킨다 |
| 4.5 | 자재·구매·재고 관리 | 전술–운영 | 소재·부품·가스·화학물질을 끊김 없이 공급한다 |
| 4.6 | 품질·수율 관리 접점 | 운영 | 수율·품질 이슈를 계획과 출하에 반영한다 |
| 4.7 | 생산원가 관리 | 전술 | 웨이퍼·칩 단위 원가를 계산하고 손익 개선 과제를 찾는다 |
| 4.8 | 제조 IT·자동화 | 운영(시스템) | MES·반송 자동화·디스패칭 시스템을 구축·운영한다 |
| 4.9 | 후공정 생산관리 | 전술–운영 | 패키징·테스트 라인의 계획과 운영, HBM 적층 관리 |

## 정보와 의사결정의 흐름

```
[시장·고객 수요]
      │  수요 예측, 고객 주문
      ▼
 4.1 수요·공급 계획(S&OP) ◀──── 4.3 Capa 관리 (공급 가능량)
      │  제품별 공급 목표
      ▼
 4.2 생산계획 ──── 웨이퍼 투입 계획 ───▶ 4.5 자재 소요 계획
      │
      ▼
 4.4 라인 운영 (FAB)  ◀── 4.8 MES·디스패칭 시스템
      │  실적·재공·생산기간
      ├──▶ 4.6 수율·품질 (양품 수 확정)
      ▼
 4.9 후공정 (패키징·테스트) ──▶ 출하
      │
      └──▶ 4.7 원가 관리 (실적 기반 원가 → 다음 계획에 반영)
```

핵심은 **위에서 계획이 내려오고, 아래에서 실적이 올라와 다음 계획을 수정하는 순환 구조**라는 점이다. 면접에서 "생산관리가 무엇이냐"는 질문에 이 흐름을 한 문장으로 설명할 수 있어야 한다.

## 실제 채용 직무명과의 대응

국내 메모리 기업의 신입 채용은 위 9개 세부직무 단위로 열리지 않는다. 대략적인 대응은 다음과 같다(정확한 직무명은 매년 공고에서 확인).

| 공고에서 볼 수 있는 직무명(예) | 주로 포함되는 세부직무 |
|---|---|
| 생산관리 / 양산관리 | 4.1, 4.2, 4.3, 4.4, 4.7, 4.9 |
| SCM / 공급망 관리 | 4.1, 4.5 |
| 구매 | 4.5 |
| 품질관리 / 품질보증 | 4.6 |
| 제조 IT / 소프트웨어(제조 시스템) | 4.8 |
| 경영지원(원가·관리회계) | 4.7 |

참고 자료에서 확인되는 직무 설명은 다음과 같다.

- **삼성전자 메모리사업부 생산관리**: "제품 생산 계획, 생산성 관리, 시스템 기반 SCM 구축을 통해 생산성을 관리하는 직무"로 소개된다(채용 홈페이지 인용, 2차 자료) [R9]. 사업부가 달라도 수율·가동률·재공·리드타임·납기 준수 관리가 본질이라는 설명이 있다 **(현직자 답변 기준)** [R9b].
- **SK하이닉스 양산관리**: 팹 안의 대량 데이터를 분석해 병목을 미리 해결하고, 공정 간 이해관계를 조율해 생산성을 높이는 역할로 소개되며, 경력이 자동화나 SCM 전문가로 이어질 수 있다고 설명된다 [R11]. 현직자들은 제조원가·손익 관리, 팹·제품별 진도 관리, 신제품 양산 관리, 수요 변화에 따른 생산 일정 수립·운영을 핵심 업무로 꼽는다 **(현직자 답변 기준)** [R10].

> **주의**: 생산관리 채용 인원은 해마다 변동이 크며, 필요할 때만 뽑거나 내부 전환으로 충원하기도 한다는 현직자 의견이 있다 **(현직자 답변 기준)** [R9b]. 생산관리 한 직무만 바라보기보다 SCM·구매·품질·제조 IT 같은 인접 직무까지 함께 준비 범위에 두는 것이 안전하다.
