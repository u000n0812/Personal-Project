# 부록 A. 용어집 {.unnumbered}

| 용어 | 뜻 |
|---|---|
| AMHS | 자동반송시스템. 웨이퍼 용기를 장비 사이로 자동 이동 |
| APS | 고급 계획·스케줄링 시스템 |
| Capa | 생산능력(Capacity) |
| CONWIP | 라인 내 재공을 일정하게 유지하며 투입하는 통제 방식 |
| Cycle Time | 생산기간. 투입부터 완성까지 걸린 시간 |
| Dispatching | 장비가 다음에 처리할 로트를 정하는 일 |
| DOI | 재고일수(Days of Inventory) |
| EDS·Probe Test | 웨이퍼 상태에서 칩별 전기적 특성 검사 |
| Excursion | 공정·품질의 비정상 변동 |
| Fab Out | 팹 공정을 마치고 나온 웨이퍼 |
| FDC | 장비 이상 감지(Fault Detection and Classification) |
| FOUP | 300mm 웨이퍼 운반 용기 |
| HBM | 고대역폭 메모리. D램 칩을 수직 적층하고 TSV로 연결 |
| Hold | 품질 등의 이유로 로트 진행을 멈춘 상태 |
| Hot Lot | 최우선 처리 로트 |
| Hybrid Bonding | 범프 없이 구리 패드를 직접 접합하는 차세대 적층 기술 |
| Lot | 함께 이동·처리되는 웨이퍼 묶음 |
| MES | 생산실행시스템 |
| Move | 처리된 공정 단계 수(웨이퍼 × 스텝) |
| MPS·MRP | 기준생산계획·자재소요계획 |
| MR-MUF / TC-NCF | HBM 적층 방식(SK하이닉스 / 삼성전자) |
| OEE | 종합설비효율 = 가용률 × 성능 × 품질 |
| OHT | 천장 반송 장치 |
| OSAT | 후공정 외주 전문 기업 |
| OTD | 납기 준수율 |
| Q-time | 공정 간 허용 대기 시간 제약 |
| Re-entrant Flow | 같은 장비 그룹을 반복 방문하는 재진입 흐름 |
| Reticle | 노광 공정의 마스크 |
| RTD | 실시간 디스패칭 시스템 |
| S&OP | 판매·생산 계획 조정 프로세스 |
| Tech Migration | 공정 세대 전환 |
| TSV | 실리콘관통전극 |
| Turn | Move ÷ WIP. 재공 회전 속도 |
| WIP | 재공. 라인 내에서 처리 중인 웨이퍼 |
| X-factor | 실제 생산기간 ÷ 이론 생산기간 |
| Yield | 수율 |
