# 취업 준비 전략

## 전공과 지원 자격

생산관리 직군은 산업공학 전공자가 많이 지원하지만, 전공만으로 선발하는 직무는 아니다. 생산계획·SCM·생산성 개선·데이터 분석 경험을 얼마나 설득력 있게 연결하는지가 중요하며, 우대 전공에 통계학이 포함된 사례도 있다 **(현직자 답변 기준)** [R10]. 산업공학 외 전공자는 **생산관리 기본 이론 + 데이터 분석 경험**으로 전공 격차를 메울 수 있다.

## 역량 개발 로드맵

### 1단계: 이론 기초(필수)
| 주제 | 핵심 내용 | 추천 자료 |
|---|---|---|
| 생산 시스템 원리 | 리틀의 법칙, 가동률–생산기간 관계, 병목, 변동성 | *Factory Physics* [R2] |
| 반도체 생산 특수성 | 재진입 흐름, 디스패칭, Capa 계획 | Mönch 외 *Production Planning and Control for Semiconductor Wafer Fabrication Facilities* [R1] |
| 생산기간 관리 | X-factor, 하키스틱 효과 | FabTime 생산기간 튜토리얼 [R3] |
| 생산관리 일반 | MPS, MRP, 재고 관리, S&OP | 학부 생산관리·SCM 교재 |
| 반도체 공정 기초 | 8대 공정, 메모리 구조, HBM | 기업 뉴스룸 기술 콘텐츠 |

### 2단계: 도구 역량(필수)
- **스프레드시트**: 피벗, 조회 함수, 시나리오 분석
- **SQL**: 조인, 집계, 윈도 함수(생산 실적 데이터 다루기)
- **Python**: pandas(데이터 처리), 시각화, SimPy(이산사건 시뮬레이션), PuLP 등(선형계획)

### 3단계: 경험 만들기(차별화)
면접관이 "이 사람은 생산관리를 해본 적이 있다"고 느끼게 하는 미니 프로젝트 예시다.

| 프로젝트 | 내용 | 연결되는 직무 |
|---|---|---|
| 리틀의 법칙 검증 시뮬레이션 | 투입량을 바꿔가며 WIP·생산기간·처리율 관계 확인 | 4.2, 4.4 |
| 디스패칭 규칙 비교 | 재진입 라인 모델에서 FIFO·EDD·CR 성능 비교 | 4.4, 4.8 |
| Capa 계산 모델 | 가상 제품 구성으로 장비 그룹별 필요 대수 산출, 가동률 목표 민감도 분석 | 4.3 |
| 수요 예측 | 공개 데이터(메모리 가격·출하 통계 등)로 시계열 예측 | 4.1 |
| 원가 모델 | 웨이퍼 원가 → 칩당 원가 → 수율·가동률 민감도 | 4.7 |

공모전, 산학 프로젝트, 제조업 인턴(업종 무관) 경험도 같은 틀로 정리하면 된다. **"어떤 지표를, 어떤 방법으로, 얼마나 개선했는가"**를 숫자로 말할 수 있어야 한다.

### 4단계: 자격증(보조)
자격증은 필수가 아니며 경험을 대체하지 못한다. 다만 이론 학습의 구조를 잡는 데 도움이 된다.

| 자격증 | 성격 | 관련 직무 |
|---|---|---|
| ASCM CPIM / CSCP | 생산·재고 계획 / 공급망 국제 자격 [R16] | 4.1, 4.2, 4.5 |
| SQLD, ADsP | 데이터 처리·분석 국내 자격 | 전 직무 |
| 품질경영기사, 6시그마 벨트 | 품질 관리 | 4.6 |
| 물류관리사 | 물류·공급망 | 4.5, 4.9 |

## 자기소개서·면접 준비

### 지원 동기 구성
1. **왜 반도체인가**: 산업의 특성(재진입 흐름, 고가 설비, 시황)을 근거로, 생산관리 역량이 가장 큰 가치를 내는 산업이라는 논리
2. **왜 메모리·이 회사인가**: HBM, 신규 팹 램프업 같은 최신 동향(6장)과 연결
3. **왜 이 직무인가**: 3단계의 경험을 지원 세부직무(5.3절 성향표 참고)와 연결

### 자주 나오는 질문 유형과 답변 뼈대
| 질문 유형 | 예시 | 답변 뼈대 |
|---|---|---|
| 개념 | 리틀의 법칙을 설명하라 | 공식 → 의미(과잉 투입의 해악) → 실제 적용 |
| 상황 대응 | 병목 장비 고장, 수요 급증, 자재 결품 | 영향 파악 → 대안 → 우선순위 → 공유(4장 각 절 참고) |
| 트레이드오프 | 가동률을 높이면? 감산하면? | 양쪽 효과를 수치 관계로 비교 |
| 직무 이해 | 생산관리와 생산기술의 차이 | 생산관리 = 흐름·계획·자원 배분, 생산기술 = 공정·설비 기술 |
| 협업 | 공정 엔지니어와 의견이 충돌하면 | 데이터로 합의 기준 만들기 |

### 직무 이해를 보여주는 표현
- "생산관리는 계획이 내려가고 실적이 올라오는 순환을 관리하는 일이다"(3.2절)
- "많이 넣는다고 많이 나오지 않는다"(리틀의 법칙)
- "가동률 100%는 목표가 아니라 위험 신호다"(하키스틱 효과)
- "메모리 생산관리의 성과는 웨이퍼가 아니라 비트와 원가로 측정된다"(2.3절)
