# 사용법 {.unnumbered}

**이 문제집의 성격.** SK하이닉스 2026 하반기 Half-Day 면접의 구성(문제해결 PT, 심층 인터뷰, 그룹 토의, A!SK)에 맞춰 양산관리 직무 중심으로 만든 **예상 문제**다. 실제 출제 문항이 아니다. 과제 속 숫자는 모두 연습용 **가정 수치**이며, 실제 회사 수치와 무관하다.

**연습 루틴.**

| 파트 | 연습 방법 | 시간 |
|---|---|---|
| 1. 문제해결 PT | LLM(ChatGPT, Claude 등)에 과제를 붙여넣고 단계별로 질문해 풀이 → 3분 발표 녹음 | 과제당 35분 + 발표 3분 |
| 2. 심층 인터뷰 | 질문에 답하고, 꼬리질문까지 이어서 답하기. 스터디원이 면접관 역할 | 질문당 3–5분 |
| 3. 그룹 토의 | 3–5명이 주제 하나로 토론. 1명은 관찰자로 체크리스트 기록 | 주제당 20–30분 |
| 4. A!SK | 휴대폰 카메라로 녹화, 질문당 1분 | 질문당 1분 + 다시 보기 |

**문제해결 PT 풀이 순서(권장).**

1. **AI 없이 3분**: 문제 한 줄 정의, 핵심 지표, 내 가설을 메모한다.
2. **구조화**: 쟁점, 빠진 정보, 가정을 AI와 정리한다.
3. **분석**: 데이터 계산을 시킨다. "식과 중간값을 모두 보여줘"를 꼭 붙인다.
4. **대안 비교**: 대안 3개를 비용·리스크·속도·고객 영향으로 비교한다.
5. **검증**: AI 답의 오류와 면접관의 반론을 찾게 하고, **핵심 숫자는 직접 검산**한다.
6. **정리**: 결론 → 근거 3개 → 리스크와 대응 → 실행 계획(단기/중기).

**질문 형식.**

```
[역할] 너는 반도체 메모리 팹의 양산관리 담당자다.
[상황] (과제 원문과 데이터)
[목표] 지금 알고 싶은 것 한 가지
[제약] 과제에 없는 사실은 지어내지 말고 '가정'으로 표시. 계산은 식과 중간값을 모두 보여줄 것.
[출력] 표 또는 번호 목록, 항목당 2줄 이내
```

**정답 확인.** 문제해결 PT의 검산용 핵심 수치와 풀이 방향은 맨 뒤 **해설**에 있다. 먼저 풀고 나서 확인할 것.

# 문제해결 PT (LLM 활용)

각 과제는 상황 → 데이터 → 요구사항 → 체크포인트 순서다. 체크포인트는 정답이 아니라 **발표에 들어가야 할 관점**이다.

## 과제 1. 서버용 D램 수요 20% 급증

**상황.** 영업에서 다음 분기부터 서버용 DDR5(제품 A) 수요가 현재보다 20% 늘어난다고 통보했다. 팹은 제품 A와 모바일용 LPDDR(제품 B)을 생산한다.

**데이터(가정).**

| 항목 | 값 |
|---|---|
| 현재 월 웨이퍼 투입 | A 30,000장, B 20,000장 |
| 팹 생산기간 | 약 3개월 |
| 제품 A 완제품 재고 | 2주분 |
| 병목 장비(노광) 가동률 | 88% |
| 노광 부하(웨이퍼 1장당) | A = 1.2, B = 1.0 (상대값) |
| 노광 목표 가동률 상한 | 90% |

**요구사항.**

1. 기간별(즉시 / 1–3개월 / 3개월 이후) 공급 방안을 제시하라.
2. A 투입을 20% 늘리면 노광 가동률이 얼마가 되는지 계산하고, 실행 가능한 투입 계획을 제시하라.
3. 공급이 부족한 기간의 배분 원칙을 제시하라.

**체크포인트.** 추가 투입분이 생산기간만큼 늦게 나온다는 점 / 병목 부하 계산 / 제품 B 조정의 손익과 고객 영향 / 배분 기준의 사전 합의

## 과제 2. 병목 장비 3일 고장

**상황.** 노광 장비 10대 중 2대가 부품 문제로 3일간 멈춘다.

**데이터(가정).**

| 항목 | 값 |
|---|---|
| 노광 처리 능력(10대 정상 시) | 하루 4,000 패스(웨이퍼 × 노광 단계) |
| 현재 노광 앞 대기 재공 | 6,000 패스 |
| Q-time 제약 로트 | 300장 (세정 후 4시간 이내 노광 필요, 초과 시 재세정) |
| 고객 인증용 HBM 샘플 로트 | 50장 (납기 5일 후) |
| 일반 로트 | 나머지 |

**요구사항.**

1. 3일간 손실되는 노광 처리량과, 고장 기간 동안 대기 재공 변화를 추정하라.
2. 로트 처리 우선순위 원칙을 제시하라.
3. 앞 공정(세정 등)에 어떤 조치를 요청할지 제시하라.
4. 복구 후 만회 계획과 보고 대상을 정리하라.

**체크포인트.** 손실량 계산 / Q-time 로트와 고객 샘플의 우선순위 근거 / 앞 공정 투입 조절로 재세정 손실 방지 / 영업·계획 부서 공유

## 과제 3. 생산기간 15% 악화 원인 분석

**상황.** 하루 출하량은 그대로인데 팹 평균 생산기간이 늘었다.

**데이터(가정).** 하루 Fab Out 2,000장(지난달과 동일)

| 장비 그룹 | 가동률(지난달 → 이번달) | 대기 재공(장, 지난달 → 이번달) |
|---|---|---|
| 노광 | 82% → 91% | 8,000 → 14,000 |
| 식각 | 78% → 80% | 9,000 → 9,500 |
| 증착 | 70% → 72% | 12,000 → 11,500 |
| CMP | 75% → 74% | 11,000 → 11,000 |

**요구사항.**

1. 리틀의 법칙으로 지난달과 이번달 생산기간을 계산하라.
2. 생산기간 악화에 가장 크게 기여한 구간을 근거와 함께 제시하라.
3. 원인을 확정하기 위해 추가로 필요한 데이터를 제시하라.
4. 단기·중기 개선안을 제시하라.

**체크포인트.** 리틀의 법칙 계산 / 가동률–대기 시간 관계(1 ÷ (1 − 가동률)) / 데이터의 한계 인정 / 원인 가설별 확인 데이터

## 과제 4. HBM과 범용 D램 웨이퍼 배분

**상황.** 다음 달 D램 웨이퍼 투입 가능량 40,000장을 HBM용과 범용 DDR5용으로 나눠야 한다.

**데이터(가정).**

| 항목 | HBM용 | 범용 DDR5 |
|---|---|---|
| 웨이퍼 1장당 공헌이익(수율 반영, 상대값) | 3.0 | 1.0 |
| 고객과 약속한 물량(웨이퍼 환산) | 10,000장 | 20,000장 |
| 후공정 제약 | TSV·적층 라인이 월 12,000장 분량까지 처리 가능 | 없음 |
| 기타 | 차기 HBM 고객 인증 결과는 2개월 후 발표 | 범용 가격 최근 하락세 |

**요구사항.**

1. 공헌이익을 최대화하는 배분안을 계산하라.
2. 고객 약속, 후공정 제약, 인증 리스크를 반영한 최종 배분안을 제시하라.
3. 다음 분기를 위해 어떤 생산능력을 늘려야 하는지 제안하라.

**체크포인트.** 제약 조건(후공정)이 배분을 결정한다는 점 / 약속 물량 우선 / 인증 실패 시 HBM 재고 리스크 / 병목이 후공정에 있다는 투자 시사점

## 과제 5. 메모리 가격 하락기의 감산 판단

**상황.** 메모리 가격이 떨어지고 재고가 쌓이고 있다. 경영진이 감산 여부 검토를 요청했다.

**데이터(가정).**

| 항목 | 값 |
|---|---|
| 현재 월 투입 | 50,000장 |
| 월 고정비 | 1,000억 원 |
| 웨이퍼당 변동비 | 100만 원 |
| 웨이퍼 환산 판매가 | 400만 원 → 250만 원으로 하락 |
| 월 수요(웨이퍼 환산) | 42,000장 |
| 현재 재고 | 6주분 (적정 3주분) |
| 감산안 | 투입 20% 축소(40,000장) |

**요구사항.**

1. 현 수준 유지와 감산 시 웨이퍼당 원가(고정비 + 변동비)를 각각 계산하라.
2. 두 안의 월 재고 변화와 공헌이익을 비교하라(판매량은 수요까지만 가능하다고 가정).
3. 감산·유지 외의 대안을 포함해 권고안을 제시하라.

**체크포인트.** 고정비 분산 효과 / 판매가 > 변동비이면 공헌이익은 양(+) / 재고 누적의 가격 리스크 / 제품 구성 전환, 웨이퍼 상태 재고 같은 대안

## 과제 6. 신규 팹 6개월 램프업 계획

**상황.** 신규 팹을 가동한다. 최종 목표는 월 30,000장 투입이다. 첫 6개월의 투입·출하 계획을 세워야 한다.

**데이터(가정).**

| 항목 | 값 |
|---|---|
| 노광 장비 반입 | 1–3개월 차 목표 대수의 50%, 4개월 차부터 100% |
| 기타 장비 | 3개월 차부터 100% (1–2개월 차는 70%) |
| 생산기간 | 3개월 (투입 후 3개월 뒤 Fab Out) |
| 예상 수율(Fab Out 시점 기준) | 첫 Fab Out 달 50% → 매월 10%p 상승, 최대 85% |
| 공정 인증 | 1개월 차는 인증용 소량 투입만 가능 |

**요구사항.**

1. 월별 최대 투입 가능량을 장비 제약으로 계산하라.
2. 월별 투입 계획과 첫 Fab Out 시점, 6개월 차까지의 양품 웨이퍼 환산량을 제시하라.
3. 램프업의 주요 리스크 3개와 대응을 제시하라.

**체크포인트.** 가장 늦게 갖춰지는 장비가 상한을 정한다 / 생산기간 때문에 출하는 4개월 차부터 / 수율 곡선 반영 / 장비 반입 지연·수율 정체·인력 숙련 리스크

## 과제 7. 특수가스 공급 2주 차질

**상황.** 핵심 특수가스 X의 주 공급사(물량의 70%)가 설비 사고로 2주간 공급을 중단한다.

**데이터(가정).**

| 항목 | 값 |
|---|---|
| 하루 사용량 | 100 단위 |
| 현재 재고 | 600 단위 |
| 보조 공급사 | 평소 하루 30 단위 → 최대 40 단위까지 증량 가능 |
| 대체 가스 인증 기간 | 6주 |
| 가스 X 사용 공정 | 제품 A·B 모두 사용, 제품 B가 단계 수 기준 1.5배 사용 |

**요구사항.**

1. 재고가 며칠 만에 바닥나는지, 2주간 부족량이 얼마인지 계산하라.
2. 부족 기간 생산 우선순위와 사용량 절감 방안을 제시하라.
3. 재발 방지를 위한 중장기 대책을 제시하라.

**체크포인트.** 순부족량 계산(사용량 − 보조 공급) / 인증 기간 때문에 대체 가스는 단기 대안이 아님 / 사용량이 많은 제품의 투입 조정 / 다변화·안전재고 정책

## 과제 8. 신제품 수율 목표 미달

**상황.** 신제품의 수율이 목표 80%에 못 미치는 70%에 머물러 있다. 고객 약속 물량을 지켜야 한다.

**데이터(가정).**

| 항목 | 값 |
|---|---|
| 고객 약속 | 월 칩 100만 개 |
| 웨이퍼당 총 칩 수 | 1,000개 |
| 현재 월 투입(목표 수율 기준으로 계획) | 1,250장 |
| 생산기간 | 3개월 |
| 수율 개선 전망 | 공정 조직은 2개월 후 75%, 4개월 후 80% 회복 예상 |

**요구사항.**

1. 현재 수율로 월 출하량과 부족량을 계산하라.
2. 약속을 지키기 위한 필요 투입량을 계산하라.
3. 생산기간을 고려한 단기 대응(앞으로 3개월)과 고객 커뮤니케이션 방안을 제시하라.

**체크포인트.** 수율 역산 / 투입 증가분은 3개월 뒤에야 출하 / 수율 회복 전망을 반영한 과잉 투입 방지 / 고객에 조기 공유

## 과제 9. 긴급 로트 남발로 생산기간 악화

**상황.** 각 부서의 긴급 로트(Hot Lot) 요청이 늘면서 평균 생산기간이 나빠졌다.

**데이터(가정).**

| 항목 | 이전 | 현재 |
|---|---|---|
| 긴급 로트 비율 | 3% | 12% |
| 긴급 로트 평균 생산기간 | 12일 | 12일 |
| 전체 평균 생산기간 | 25일 | 29일 |

**요구사항.**

1. 일반 로트의 평균 생산기간이 이전과 현재 각각 얼마인지 계산하라.
2. 긴급 로트 증가가 왜 전체 생산기간을 늘리는지 설명하라.
3. 긴급 로트 운영 정책(기준, 상한, 승인 절차, 모니터링)을 제안하라.

**체크포인트.** 가중평균 역산 / 우선 처리가 다른 로트의 대기와 변동성을 키운다는 원리 / 정량 기준과 비용 가시화

## 과제 10. AI로 양산관리 업무 개선 기획

**상황.** 팀장이 "양산관리 업무 중 하나를 골라 AI(LLM 포함)로 개선하는 방안을 기획하라"고 지시했다.

**데이터(가정).** 양산관리 담당자 1인의 업무 시간 비중

| 업무 | 비중 |
|---|---|
| 실적 집계·일일 보고서 작성 | 30% |
| 부서 간 일정·물량 조율(회의, 메일) | 25% |
| 이상 상황 대응(장비 고장, 수율 이슈) | 20% |
| 생산계획 수립·수정 | 15% |
| 기타 | 10% |

**요구사항.**

1. 개선 대상 업무를 하나 골라 선정 근거를 제시하라.

# 심층 인터뷰

각 질문에 **질문 의도**, **꼬리질문**, **답변 핵심**을 붙였다. 꼬리질문까지 막힘없이 답할 수 있어야 한다. 자기소개서가 경험기술서로 바뀌었으므로, 실제 면접에서는 본인이 쓴 경험기술서에 꼬리질문이 집중될 가능성이 크다.

## 1분 자기소개와 양산관리 지원 이유

- **질문 의도**: 직무 이해를 바탕으로 지원했는가
- **꼬리질문**: ① 양산관리 말고 고민한 직무는? ② 입사 5년 뒤 어떤 전문가가 되고 싶은가?
- **답변 핵심**: 나를 한 문장으로 정의 → 근거 경험 1개(수치 포함) → 양산관리와의 연결

## 왜 반도체이고, 왜 SK하이닉스인가

- **질문 의도**: 업종·회사 선택의 논리. 직무와 관계없이 거의 반드시 나온다는 후기가 많다.
- **꼬리질문**: ① 같은 일은 다른 제조업에서도 할 수 있는데 왜 반도체인가? ② 경쟁사가 아니라 SK하이닉스여야 하는 이유는?
- **답변 핵심**: 반도체 생산의 특수성(재진입 흐름, 고가 설비, 시황 변동)이 생산관리 역량의 가치를 가장 크게 만든다는 논리 + HBM 확대, 청주 M15X·용인 클러스터 같은 생산 확대 국면과 내 역량의 연결

## 경험기술서 속 가장 어려웠던 문제와 해결 과정

- **질문 의도**: 문제 정의와 해결 과정의 깊이, 본인의 실제 역할
- **꼬리질문**: ① 그 방법을 택한 이유와 다른 대안은? ② 결과를 숫자로 말하면? ③ 다시 한다면 무엇을 바꾸겠는가?
- **답변 핵심**: 상황 → 내가 정의한 문제 → 판단 근거 → 행동 → 수치 결과 → 배운 점

## 데이터로 다른 사람을 설득한 경험

- **질문 의도**: 양산관리의 핵심인 "숫자로 다른 부서를 움직이는 능력"
- **꼬리질문**: ① 상대가 끝까지 동의하지 않았다면? ② 데이터가 불완전했다면 어떻게 했겠는가?
- **답변 핵심**: 상대의 입장 → 내가 준비한 데이터와 분석 → 합의 기준을 만든 과정 → 결과

## 양산관리는 무슨 일을 하는가

- **질문 의도**: 직무 이해도, 인접 직무와의 구분
- **꼬리질문**: ① 생산기술·공정기술과 무엇이 다른가? ② 양산관리가 잘하고 있다는 것은 어떤 지표로 알 수 있는가?
- **답변 핵심**: 계획이 내려가고 실적이 올라오는 순환을 관리하는 일. 팹 데이터를 분석해 병목을 미리 해결하고 공정 간 이해관계를 조율해 생산성을 높이는 역할. 핵심 지표는 생산기간, 재공, 가동률, 계획 달성률, 납기 준수율

## 생산관리 기본 개념

- **질문 의도**: 직무 전문성의 기초
- **꼬리질문**: ① 리틀의 법칙을 설명하라 ② 가동률 100%는 좋은가? ③ 병목은 어떻게 찾는가?
- **답변 핵심**: 재공 = 처리율 × 생산기간 → 과잉 투입은 처리율을 늘리지 못하고 재공·생산기간만 늘린다 / 가동률이 높을수록 대기 시간이 급증 / 재공이 쌓이는 곳과 가동률이 높은 곳을 함께 본다

## HBM 시대 양산관리의 과제

- **질문 의도**: 회사 핵심 사업에 대한 관심과 직무 관점의 이해
- **꼬리질문**: ① HBM 생산이 일반 D램보다 어려운 이유는? ② 양산관리자로서 무엇에 기여할 수 있는가?
- **답변 핵심**: 전공정과 후공정의 강한 연결(TSV·적층), 적층 수율의 누적, 고객 인증 일정에 묶인 생산 → 전·후공정을 하나의 흐름으로 계획하는 역할

## 이해관계가 충돌한 상황을 조율한 경험

- **질문 의도**: 공정·설비·품질 등 여러 부서 사이의 조율 역량
- **꼬리질문**: ① 본인 의견이 틀렸던 적은? ② 조율에 실패했다면 원인은?
- **답변 핵심**: 각자의 목표 파악 → 공통 목표와 판단 기준 제시 → 데이터로 대안 비교 → 합의와 후속 관리

## 실패 경험과 그 후의 변화

- **질문 의도**: 회복력, 자기 객관화
- **꼬리질문**: ① 실패의 원인 중 본인 몫은? ② 그 교훈을 실제로 적용한 사례는?
- **답변 핵심**: 실패를 축소하지 않기 → 원인 분석에서 내 책임 인정 → 바뀐 행동 → 이후 적용 사례

## AI 시대에 사람의 역할은 무엇인가 (인문학적 소양)

- **질문 의도**: 평가 요소인 인문학적 소양, 기술을 보는 관점
- **꼬리질문**: ① AI가 생산계획을 대부분 자동화하면 양산관리자는 무엇을 해야 하는가? ② AI의 결정으로 문제가 생기면 책임은 누구에게 있는가?
- **답변 핵심**: 규칙을 직접 정하는 사람에서 AI의 답을 검증하고 개선하는 사람으로 역할 이동 / 판단의 책임은 사람에게 남는다는 관점 / 최근 읽은 책이나 사회 이슈에서 근거 하나를 준비

# 그룹 토의

정답이 없는 주제다. 이기는 것이 아니라 **합의로 가는 과정에 어떻게 기여하는지**를 본다. 각 주제에 **쟁점**, **입장별 논거**, **기여 포인트**를 정리했다.

**관찰자 체크리스트**: 쟁점을 정의했는가 / 판단 기준을 제안했는가 / 다른 의견을 요약·통합했는가 / 근거(숫자·사례)를 들었는가 / 말을 끊거나 독점하지 않았는가 / 시간 안에 결론을 정리했는가

## AI가 생산계획을 자동화하면 양산관리자의 역할은 줄어드는가

- **쟁점**: 자동화의 범위와 사람의 역할
- **입장 A**: 반복 업무는 대부분 자동화되므로 인력과 역할이 줄어든다
- **입장 B**: 예외 상황 대응, 부서 간 조율, AI 결과 검증과 책임은 사람이 맡으므로 역할은 바뀔 뿐 줄지 않는다
- **기여 포인트**: 업무를 반복성과 판단 필요성으로 나누는 기준을 제안

## 한정된 생산능력을 HBM과 범용 D램에 어떻게 배분할 것인가

- **쟁점**: 단기 수익성 vs 고객 기반·리스크 분산
- **입장 A**: 수익성이 높은 HBM에 최대한 배분해야 한다
- **입장 B**: 범용 제품 고객을 잃으면 시황 변화 때 위험하므로 일정 비율을 지켜야 한다
- **기여 포인트**: 고객 약속 물량 → 제약 조건(후공정) → 수익성 순서의 배분 원칙 제안

## 메모리 불황기에 감산해야 하는가, 생산을 유지해야 하는가

- **쟁점**: 원가 상승 vs 재고·가격 리스크
- **입장 A**: 재고가 쌓이면 가격이 더 떨어지므로 감산해야 한다
- **입장 B**: 고정비 비중이 커서 감산하면 칩당 원가가 올라가고, 회복기 공급 기회를 놓친다
- **기여 포인트**: 제품 구성 전환, 웨이퍼 상태 재고처럼 이분법이 아닌 대안을 제시

## 신규 팹은 수도권에 집중해야 하는가, 지방에 분산해야 하는가

- **쟁점**: 인재 확보·클러스터 효과 vs 전력·용수·지역 균형
- **입장 A**: 인재와 협력사가 모인 수도권 클러스터가 효율적이다
- **입장 B**: 전력·용수 확보와 지역 균형, 재해 리스크 분산을 위해 분산해야 한다
- **기여 포인트**: 평가 기준(인재, 인프라, 비용, 리스크, 사회적 책임)을 표로 정리 제안

## 공급망: 비용 효율이 우선인가, 공급 안정이 우선인가

- **쟁점**: 원가 절감 vs 다변화·국산화 비용
- **입장 A**: 경쟁력은 원가에서 나오므로 가장 싼 공급처에 집중해야 한다
- **입장 B**: 자재 하나가 끊기면 팹 전체가 멈추므로 비용이 들더라도 다변화해야 한다
- **기여 포인트**: 자재를 중요도로 분류해 분류별로 다른 전략을 쓰자는 절충안

## 고객이 긴급 납기를 요청할 때 품질 검증 기간을 줄일 수 있는가

- **쟁점**: 고객 대응 속도 vs 품질 리스크
- **입장 A**: 핵심 고객을 잃지 않으려면 위험이 낮은 검증 항목은 줄일 수 있다
- **입장 B**: 품질 사고가 나면 신뢰 손실이 훨씬 크므로 검증은 줄일 수 없다
- **기여 포인트**: 검증을 줄이는 대신 병렬 진행, 우선순위 조정 같은 일정 단축 대안 제시

## 교대 근무 현장과 주간 사무 조직의 소통을 어떻게 개선할 것인가

- **쟁점**: 정보 전달 시차, 서로 다른 우선순위
- **입장 A**: 시스템(대시보드, 자동 알림)으로 정보 격차를 없애야 한다
- **입장 B**: 시스템만으로는 맥락이 전달되지 않으므로 정기적인 대면 소통이 필요하다
- **기여 포인트**: 정보 유형별(긴급·정기·맥락)로 수단을 나누는 안

## 채용에서 학력보다 역량을 보는 방향은 바람직한가

- **쟁점**: 공정성과 다양성 vs 검증 비용과 신뢰성
- **입장 A**: 실제 문제 해결 과정을 보는 것이 더 정확하고 공정하다
- **입장 B**: 역량 평가는 시간과 비용이 많이 들고 평가자 주관이 개입될 수 있다
- **기여 포인트**: 평가의 일관성을 높이는 장치(표준 과제, 복수 평가자)를 제안

## 생산 확대와 탄소·전력 감축은 함께 갈 수 있는가

- **쟁점**: 성장 vs 환경 책임
- **입장 A**: 경쟁에서 밀리면 안 되므로 생산 확대가 우선이고 환경은 기술 발전으로 해결한다
- **입장 B**: 전력 확보와 고객사의 탄소 감축 요구가 이미 사업 리스크이므로 동시에 추진해야 한다
- **기여 포인트**: 생산 효율 향상(같은 전력으로 더 많은 생산)이 두 목표를 함께 달성한다는 연결 고리 제시

## 사내에서 생성형 AI 사용 범위를 어디까지 허용할 것인가

- **쟁점**: 업무 효율 vs 기술·데이터 유출 위험
- **입장 A**: 효율이 크게 오르므로 적극 허용하고 사후 관리해야 한다
- **입장 B**: 공정·고객 정보가 유출되면 피해가 막대하므로 엄격히 제한해야 한다
- **기여 포인트**: 데이터 등급별 허용 범위, 사내 전용 모델 활용 같은 단계적 허용안

# 해설: 문제해결 PT 검산과 풀이 방향 {.unnumbered}

아래 수치는 문제의 가정 데이터로 계산한 값이다. 풀이 방향은 하나의 예시이며 다른 결론도 근거가 타당하면 좋은 답이다.

**과제 1.**

- 현재 노광 부하 = 30,000 × 1.2 + 20,000 × 1.0 = 56,000 (가동률 88%)
- A를 20% 늘리면(+6,000장) 부하 = 56,000 + 7,200 = 63,200 → 가동률 = 88% × 63,200 ÷ 56,000 ≈ **99.3%** → 실행 불가(생산기간 급증)
- 가동률 상한 90%일 때 최대 부하 = 56,000 × 90 ÷ 88 ≈ 57,273 → 추가 여유 약 1,273 → B를 줄이지 않으면 A는 약 **1,060장**만 추가 가능
- 방향: 즉시는 재고 2주분, 1–3개월은 재공 우선순위 조정, 3개월 이후는 A 추가 투입 + B 일부 감축(B 1장을 A 1장으로 바꾸면 노광 부하는 0.2 증가). B 감축은 B 고객 약속과 손익으로 판단. 부족 기간 배분 기준을 영업과 사전 합의.

**과제 2.**

- 손실 처리량 = 4,000 × 2/10 × 3일 = **2,400 패스**
- 고장 중 하루 처리 능력 3,200 패스. 앞 공정에서 평소처럼 하루 4,000 패스가 도착하면 대기 재공은 하루 800씩 늘어 3일 후 약 **8,400 패스**
- 방향: Q-time 로트(재세정 손실 방지)와 고객 인증 샘플을 최우선 → 앞 공정에 투입 조절 요청(특히 세정 후 바로 노광해야 하는 로트의 세정 시점 조정) → 복구 후 만회 계획과 출하 영향을 영업·계획 부서에 공유

**과제 3.**

- 총 재공 = 40,000장 → 46,000장. 생산기간 = 재공 ÷ 처리율 = 40,000 ÷ 2,000 = **20일** → 46,000 ÷ 2,000 = **23일** (+15%)
- 재공 증가 6,000장은 사실상 전부 노광 앞에 쌓임(식각 +500, 증착 −500, CMP 0)
- 노광 대기 배수 근사: 1 ÷ (1 − 0.82) ≈ **5.6** → 1 ÷ (1 − 0.91) ≈ **11.1**
- 추가 데이터: 제품 구성 변화(노광 단계가 많은 제품 비중), 노광 장비 가용 대수(고장·정비), 투입량 변화
- 방향: 단기는 노광 앞 투입 조절과 노광 우선 디스패칭, 중기는 원인에 따라 제품 구성 조정 또는 장비 추가

**과제 4.**

- 이익만 보면 HBM에 전부 배분하고 싶지만 후공정 상한이 **12,000장** → HBM 12,000장, DDR5 28,000장
- 공헌이익 = 12,000 × 3.0 + 28,000 × 1.0 = **64,000** (상대값). 약속 물량(HBM 10,000, DDR5 20,000)은 모두 충족
- 인증 리스크: HBM 추가분 2,000장은 인증 결과 전에 투입되므로, 인증 실패 시 재고가 될 수 있음 → 10,000–12,000장 사이에서 리스크 선호에 따라 결정
- 투자 시사점: 병목은 웨이퍼가 아니라 **후공정(TSV·적층) 생산능력**

**과제 5.**

- 유지(50,000장): 웨이퍼당 고정비 = 1,000억 ÷ 50,000 = 200만 원 → 원가 **300만 원**
- 감산(40,000장): 웨이퍼당 고정비 = 1,000억 ÷ 40,000 = 250만 원 → 원가 **350만 원**
- 웨이퍼당 공헌이익 = 250만 − 100만 = 150만 원(양수). 판매량은 수요 42,000장까지
  - 유지: 생산 50,000장, 판매 42,000장 → 공헌이익 42,000 × 150만 = **630억 원**, 재고 **월 +8,000장**
  - 감산: 생산 40,000장, 판매 42,000장(부족 2,000장은 기존 재고로 판매) → 공헌이익 **630억 원**, 재고 **월 −2,000장**
- 핵심: 판매량이 수요로 제한되므로 두 안의 이번 달 공헌이익은 같다. 차이는 **재고 증감**(유지 시 월 8,000장 누적)과 **단위 원가**(감산 시 50만 원 상승)다
- 방향: 재고가 이미 적정 수준(3주분)의 두 배이므로, 유지하면 가격 추가 하락 위험이 커진다 → 감산을 기본으로 하되 수요가 강한 제품으로의 구성 전환, 재고를 웨이퍼 상태로 보유하는 방안을 함께 제시

**과제 6.**

- 투입 상한은 가장 부족한 장비가 결정: 1–2개월 차는 노광 50%·기타 70% → **50%(15,000장)**, 3개월 차는 노광 50% → **15,000장**, 4개월 차부터 **30,000장**. 단 1개월 차는 인증용 소량만 가능
- 생산기간 3개월이므로 첫 의미 있는 Fab Out은 2개월 차 투입분이 나오는 **5개월 차**(1개월 차 인증 소량은 4개월 차)
- 수율: 첫 Fab Out 달(4개월 차, 인증 소량) 50% → 5개월 차 60% → 6개월 차 70%. 예) 2개월 차 15,000장 투입 → 5개월 차 양품 환산 **9,000장**, 3개월 차 15,000장 → 6개월 차 **10,500장**
- 리스크: 장비 반입 지연, 수율 향상 정체, 인력 숙련. 대응: 반입 일정 주간 점검, 수율 단계별 목표와 투입 연동, 기존 팹 인력 지원

**과제 7.**

- 하루 순부족 = 100 − 40 = 60 단위 → 재고 600 ÷ 60 = **10일**에 바닥
- 2주(14일) 중 남은 4일의 부족량 = 60 × 4 = **240 단위**(하루 사용량의 2.4일분)
- 대체 가스는 인증에 6주가 걸려 단기 대안이 아님
- 방향: 사용량이 많은 제품 B의 투입을 우선 조정하고 제품 A·고객 약속 물량을 우선, 다른 팹·계열사 재고 융통 검토 → 중장기로 공급사 다변화, 안전재고 상향, 대체 가스 사전 인증

**과제 8.**

- 현재 출하 = 1,250 × 1,000 × 0.70 = **87.5만 개** → 부족 **12.5만 개**(12.5%)
- 필요 투입 = 1,000,000 ÷ (1,000 × 0.70) ≈ **1,429장**(+179장, +14.3%)
- 단, 수율이 2개월 후 75%, 4개월 후 80%로 회복될 전망이므로 지금 투입분(3개월 후 출하)은 75–80% 수율을 적용받을 수 있다 → 75% 기준 필요 투입 약 **1,334장**. 과잉 투입 주의
- 방향: 앞으로 3개월의 부족분은 투입 증가로 메울 수 없으므로 재고 활용, 고객과 조기 협의(일부 일정 조정), 수율 회복 추적과 투입량 연동

**과제 9.**

- 이전: 0.03 × 12 + 0.97 × x = 25 → x ≈ **25.4일**
- 현재: 0.12 × 12 + 0.88 × y = 29 → y ≈ **31.3일**
- 일반 로트 생산기간이 약 6일(약 23%) 늘었다. 긴급 로트를 우선 처리하면 다른 로트가 기다리고, 장비 셋업·배치 구성이 흐트러져 라인의 변동성이 커진다
- 방향: 긴급 로트 비율 상한(예: 5%), 요청 기준(고객 약속·인증 샘플 등), 승인 절차, 부서별 사용량과 영향의 주간 공개

**과제 10.**

- 선정 예: 비중이 가장 크고 반복적인 **실적 집계·일일 보고서(30%)** → 효과가 크고 실수의 위험이 비교적 낮음
- 설계 예: MES 실적 데이터 자동 집계 → LLM이 계획 대비 차이와 특이사항 초안 작성 → 담당자가 원인 판단과 조치 의견을 추가해 확정
- 지표 예: 보고서 작성 시간(예: 하루 2시간 → 30분), 오류 건수, 이상 징후 조기 발견 건수
- 리스크: 데이터 오류와 AI 요약 오류(원 데이터 링크·검증 절차), 보안(사내 전용 환경), 책임(최종 확정은 담당자)
