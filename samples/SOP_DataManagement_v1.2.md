# SOP DataManagement

문서번호: SOP-DM-011
버전: 1.2
적용일: 2023-11-01

## 1. 목적
본 SOP 는 임상 데이터 관리 업무의 표준 절차를 정의한다.

## 2. Data Management Plan
### 2.1 작성 시점
Data Management Plan(DMP)은 첫 환자 등록 전에 작성한다.
DMP 초안은 Data Manager 가 작성하고 Project Manager 가 검토한다.

### 2.2 승인
DMP 는 Data Manager 작성, Project Manager 검토, QA 담당자 승인 순으로 진행한다.
승인된 DMP 는 문서 관리 시스템에 등록한다.

## 3. CRF 설계
CRF 는 Protocol 확정 후 4주 이내에 설계를 완료한다.
CRF 설계 변경은 Change Request 를 통해서만 수행한다.

## 4. Data Entry 및 Query
### 4.1 Data Entry
기관 담당자는 방문 후 5영업일 이내에 데이터를 입력한다.

### 4.2 Query 처리
Query 는 발행 후 10영업일 이내에 응답해야 한다.
응답이 없으면 Data Manager 가 주 1회 Reminder 를 발송한다.
Query 종결은 Data Manager 가 확인 후 수행한다.

## 5. 문서 보관
프로젝트 문서는 종료 후 최소 15년간 보관한다.
전자 문서는 백업본을 별도 저장소에 보관한다.

## 6. 교육
신규 담당자는 업무 시작 전 본 SOP 교육을 이수해야 한다.
교육 기록은 교육 이수 대장에 보관한다.
